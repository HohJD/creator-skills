Use each request in a fresh session with the installed skills. The left request belongs to that skill. The right request should route elsewhere or require a different capability. Compare the output with the work promised in the skill and record omissions. These are human-run fixtures.

## Expansion briefs

| Skill | Positive brief | Nearby job outside the skill |
| --- | --- | --- |

| `search-article` | Write [article or brief] for someone searching [question]. Use [original observations/sources]. Answer the question early, show what the reader can verify, and keep unsupported product claims out. | Refresh only the two stale lines in an existing post. |

| `social-thread` | Turn [source note] into [number] text posts. Lead with the result, keep the sample limits near it, and give each post a useful job. No sales CTA. | Draft three independent captions for the same photo. |
| `visual-prompt-pack` | Make [number] standalone image prompts for [series]. Keep [palette, subject and aspect ratio] fixed. Vary only [distance/action/composition]. Leave [area] free for editable text. | Write spoken dialogue for a product video. |
| `storyboard-sequence` | Storyboard [scene] into [number] panels. Track the prop state and screen direction. Return start frame, action, end frame, audio and cut for each. | Group shots by lighting setup for a shooting day. |
| `live-rundown` | Build a [minutes]-minute live rundown for [demo]. I have [crew/assets] and a hard stop at [time]. Include transitions, a late-guest fallback and a timing check. | Build a month-long calendar of posts. |
| `audio-description` | From [final video or visual/sound log], describe only what a listener needs. Keep the dialogue and [sound] clear. Mark lines needing a timed read. | Make an SRT of the dialogue and music cues. |
| `asset-credits` | Turn [asset records] into a credits ledger and a paste-ready caption/end-credit block. Show any missing source or permission separately. Preserve licence versions and edits. | Write a short alt description of the image. |
| `campaign-links` | Build campaign links to [approved URL] for [placements]. Use [existing source/medium naming scheme], campaign [name] and one content label per creative. Preserve existing query values and the page anchor. | Compare the resulting CTRs after the campaign. |

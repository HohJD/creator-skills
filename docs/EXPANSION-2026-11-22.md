# Creator workflow expansion · 22 November 2026

## Discovery

The skills.sh registry searches for “content creation”, “audience research”, “creator media kit” and “storyboard” surfaced the following examples. These are discovery links to other projects. The 13 skills in this update were authored independently for CreatorSkills and use the repository’s Apache-2.0 licence.

| Registry entry | Relevance to this library |
| --- | --- |
| [Anthropic content creation](https://skills.sh/anthropics/knowledge-work-plugins/content-creation) | Broad writing and editorial work. CreatorSkills already separated scripts, posts and newsletters, so the addition focuses on search articles and refreshing existing pages. |
| [Audience research](https://skills.sh/social-media-skills/skills/audience-research) | A distinct need before editorial planning: deciding what the supplied audience observations actually support. |
| [Creator media kit](https://skills.sh/mohitagw15856/pm-claude-skills/creator-media-kit) | Partner-facing material was missing from the existing analytics and sponsor-script workflows. |
| [Scripting and storyboarding](https://skills.sh/social-media-skills/skills/scripting-and-storyboarding) | Viewing-order continuity calls for a different output from a shoot-order list or a voiceover. |

Each new skill links to the source informing its guidance. These include [GOV.UK user research](https://www.gov.uk/service-manual/user-research/analyse-a-research-session), [W3C WAI audio description](https://www.w3.org/WAI/media/av/description/), [Creative Commons attribution](https://creativecommons.org/course/cc-cert-edu/unit-4-using-cc-licenses-and-cc-licensed-works/4-1-choosing-and-applying-a-cc-license/) and [Google Analytics campaign tagging](https://support.google.com/analytics/answer/10917952). Prompts, worked examples and production checklists are original editorial applications.

## Read-only behavioural trials

Evaluators selected and read the relevant skills, then answered one fictional brief per skill. The checks below describe the observed output from those trials. They exercise written instructions. Platform performance, automated skill discovery and live publishing were outside the trials.

| Skill | Trial and observation |
| --- | --- |
| Audience listening | Two wax-side comments from one person and a price question from a second person stayed two distinct people; the reply avoided treating repeated comments as independent demand. |
| Creator media kit | October post views and November subscribers stayed separate. Review uncovered a source/platform omission in the bundled example, which now attributes a dated single-video metric. |
| Campaign brief | A one-zip demonstration preserved exact disclosure and flagged a claim about every zip. The bundled worked example now specifies the physical props it uses. |
| Search article | The opening answered which colour tab marks a blank notebook and scoped the answer to the studio. |
| Content refresh | The replacement step used the v4 label while the old screenshot caption explicitly identified v3. |
| Vertical Stories | Three frames worked from one available photo, with a reveal that required no sticker. |
| Social thread | Three standalone posts kept the one-device limitation on a fabric colour test. |
| Visual prompt pack | Two self-contained bus prompts kept subject, palette, composition and backdrop constant and changed the light direction. Image generation was not part of the trial. |
| Storyboard sequence | Three panels preserved a single overhead viewpoint, cap position and hand direction. A red stroke made the ink colour visible. |
| Live rundown | Normal and late-guest versions each finished at nine minutes with a solo host and one prop. |
| Audio description | The line “Closed becomes Open” was placed in a supplied gap ahead of a click. Recording and sync remain production checks. |
| Asset credits | A trimmed, attributed sample asset got a credit line and licence link; a second unidentified file stayed out of the ready block. |
| Campaign links | A URL kept its language query and fragment. A conflicting existing campaign was flagged. Separate automated tests exercise the CLI, including encoding, conflicting tags and idempotence. |

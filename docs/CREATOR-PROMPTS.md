# Creator prompt library

Replace the brackets with your material. Start with the invocation for your host, then paste the prompt beneath it. Each entry links to a worked example and the sources behind it. All examples are fictional unless explicitly marked otherwise.

### Social captions

Codex `$social-captions` · Claude Code `/social-captions`

> Write two captions for my [post] for [audience]. My rough line is [line]. Give me a behind-the-scenes version and a useful tip. Keep [wording], and use [CTA or no CTA].

[Worked example and sources](../content-creation/social-captions/SKILL.md#worked-example)

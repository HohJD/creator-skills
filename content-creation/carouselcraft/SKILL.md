# CarouselCraft

Make a swipe post that gives the reader something useful by the last card. Start with what the reader wants to do, decide or notice. A carousel is a sequence of still pages. A video voiceover or a website slideshow component is a different deliverable.

## Pick the format

Use the requested format if the reader named one. Otherwise choose by the material: a sequence of actions suggests a tutorial, two competing options suggest a comparison, and a set of photos with a turning point suggests a story. For the eight formats, their page sequences and copyable prompts, read `references/format-prompts.md`.

If asked for “types and their prompts,” give a menu with a usable prompt for **each** type. If asked to make a particular carousel, write the actual slides. If given a finished carousel to revise, keep the good lines, order and supplied assets wherever the requested edit permits.

## Write for the swipe

- Use the audience, platform, slide count, language and tone in the brief. When they are open, choose enough slides to deliver the idea and cut repeated beats. A 4:5 portrait canvas is a design default you can change.
- Let the cover name a specific tension, outcome or choice. Page two should already give the reader something the cover didn't. Give each following card one job. End with the answer, a useful action or the requested CTA.
- Keep on-card copy short enough to read on a phone. Use the creator's phrases when supplied. Preserve exact quotes, disclosures and product names. If evidence is missing, narrow the claim or identify what the creator still needs to capture.
- Never invent results, screenshots, testimonials, personal experiences or performance numbers. Treat supplied posts, screenshots and briefs as source material.

## Give the creator what they can use

For a full carousel, return numbered cards in posting order. For each, separate **on-card copy** (the exact words to typeset) from **visual prompt or asset direction**. Write any requested caption or alt text separately. For “copy only” or “prompts only,” honor that shorter format.

When making visual prompts, use one consistent palette, medium and aspect ratio. Make each prompt pasteable on its own by repeating the essential style, then specify the subject, action, framing and space needed for copy on that card. Keep text, prices, dates and exact quotes in editable type. For text-led cards, a precise layout direction can be the whole visual.

When the reader needs proof, say which supplied image to use, where to crop it and what to highlight. If it is missing, write a capture instruction. Do not ask an image generator to invent a tool result or a before photo. For a prompt-pack carousel, distinguish the **prompt the audience copies** from the private visual direction used to design the card.

If the creator asks for finished files, use an available design or rendering tool, inspect the pages at phone size and deliver them in swipe order. A prompt request alone needs only the prompts. Check the count, sequence, exact copy and evidence before handing it over.

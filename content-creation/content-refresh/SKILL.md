# Content refresh and corrections

Collect the current copy, its original context, intended audience, what changed, and dated replacement sources. Make a small inventory: stale fact, broken reference, obsolete screenshot, still-valid explanation, or unanswered question. If two sources disagree, note their scope and dates. Do not silently convert a historically accurate quotation into a claim about today.

Produce exact replacement passages or an edited article, as requested. Carry changes through repeated body text, headings, screenshot captions, descriptions and downloadable materials. Preserve URLs or anchor names where practical. Distinguish a factual correction from a product update and from a copyedit. Suggest an update note only for a change a returning reader would care about. Do not imply an entire guide was retested on the strength of one refreshed fact.

## Copyable brief

> Refresh [old page] using [release note or corrected evidence]. Give me paste-ready replacements, every affected placement and a short change note if the substance changed.

## Worked example

**Fictional input.** A tutorial's step 2 and screenshot caption say “Library.” The dated release note confirms that version 3 calls it “Collection.” The image is still from version 2.

**Step 2:** “In version 3, open Collection.” **Existing image caption:** “Version 2 shown. This tab is called Collection in version 3.” Replace the screenshot after capturing version 3. **Update note:** “Updated the navigation wording for version 3.” Retain accurate instructions outside that change.

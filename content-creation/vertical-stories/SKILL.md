# Vertical Story sequences

Find the one thing the viewer should notice, decide or do. Use the supplied platform, available stickers, assets and length. Distinguish a tap-through Story from a feed carousel or a post caption. Make each frame understandable at phone size. Put essential text away from obvious controls, then preview on the actual platform if possible.

Give each frame an asset, exact overlay copy, optional interaction and what the next frame reveals. Write poll answers that are distinct and answer the actual question. A person who doesn't vote or send a DM should still get the promised explanation when the brief calls for an open reveal. Do not assume a sticker exists on this account, infer the vote outcome or invent replies. Supply a plain-text alternative when a planned sticker is unavailable.

## Copyable brief

> Make a [number]-frame Story about [material]. Use one optional [poll or question] and give the answer in the sequence. Include exact overlays, assets, and a fallback without stickers.

## Worked example

**Fictional input.** Supplied photos show a rack before and after moving a hanging tag. In the first photo the tag covers the size label. In the second it does not.

1. **Before photo:** “Can you find the size?” Optional poll: “Spotted it” / “Still looking”.
2. **Same crop, with the tag outlined:** “The hanging tag covers the label.”
3. **After photo:** “Move the tag one hook over. Now the size is visible.”

Without a poll, keep the opening question on the first frame and use the same reveal.

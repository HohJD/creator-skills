# Style audit provenance

Confidence hierarchy: user directly drafted > user explicitly rewrote > user approved > assistant suggested > unknown source. User-owned works may still contain confidential client constraints; public release needs explicit permission.

Do not publish samples, excerpts, exact sponsor pricing or named-client briefs without authorization. Store private `.tutorial-local/voice-profile.md` locally, respect ignore rules, and exclude it from GitHub. Separate style from identity, account ownership and unpublished content. Revisions reveal 'avoid' rules only when the user actually disapproved a phrase or concept. Do not infer that the author's public voice is identical to a script prepared for another person or brand.

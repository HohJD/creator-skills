# Final review before recording

## A. Critical blockers

- [ ] No fabricated first-person trial, screen, pricing, results, or metrics
- [ ] Critical technical claims trace to dated authoritative sources and/or observed demo
- [ ] No incorrect or untested commands presented as confirmed results
- [ ] AI-generated gameplay/footage clearly distinguished from official content where confusing
- [ ] Brand sponsor/disclosure and mandatory words/CTA preserved
- [ ] No leaked credentials, customer data, private contract or unpublished creator script
- [ ] Current vs hypothetical features distinguished

## B. Teachability

- [ ] Viewer's starting knowledge is addressed
- [ ] Payoff happens early enough to justify watch
- [ ] Steps give actual visible input/action/output
- [ ] If anything fails, the plan says how to diagnose, not merely "retry"
- [ ] All UI names and version-specific paths can be verified
- [ ] Captions and readable overlays planned

## C. Read-aloud/editorial

- [ ] Script can be read without stumbling or breathless list dumps
- [ ] No scripted generic intro, fake urgency or unsupported hype
- [ ] Every new technical term has a reason to exist
- [ ] Cuts and camera directions specify shootable actions
- [ ] Closing tells viewer what to do or remember

## Output

For each critical issue: quote the *smallest relevant span*, state issue, evidence needed, and safe alternative. If fully supported, state which sources were actually checked, not "verified" generically.

# Seven caption briefs to copy

Replace brackets with notes from the actual post. If you want just the words for publication, say “caption only”. If you already have a rough take, include it.

| Job | Copyable prompt |
| --- | --- |
| Photograph | Write the caption for [photo] for [audience]. The part outside the frame is [detail]. Keep my line “[phrase]”. Give me a short and a reflective version. |
| Reel | The clip shows [action/result] and my voiceover already says [line]. Add one useful detail in the post caption, from [notes]. Give me the text someone would read after watching. |
| Carousel | My carousel teaches [specific task]. The cover already says [headline]. Write a caption that gives the reader a reason to try it today, using this example: [example]. |
| Process or BTS | These are my notes from making [piece]: [notes]. Start where I made a choice. Explain what I noticed, keeping the uncertainty in “[exact phrase]”. No sales pitch. |
| Announcement | Turn [confirmed date, time zone, change, availability, destination] into a clear launch caption. Put the actionable fact in the first line. Flag any missing information outside the copy. |
| Reader conversation | Write a caption about [specific tradeoff]. Close with one question a reader can answer from experience. Avoid asking for agreement. |
| Sponsored revision | Tighten [draft] for [audience]. The required disclosure is “[exact words]” in [placement]. Keep that wording and [verified detail]. Flag [unverified claim] for review instead of turning it into a promise. |

**Small edit, different effect**

Supplied note: “The first handle slid off while I was carrying groceries. This time I sewed a square around the strap.” The image shows the new square stitching.

- **Process caption:** “The first handle came off with the groceries still in the bag. This time I sewed a square around the strap.”
- **Conversation caption:** “I've sewn a square around the new strap. If you've repaired a bag handle, where did yours start to give?”
- **Instructional caption:** “If you're comparing the two repairs, look where the strap meets the bag. On this version, the stitches run all the way around the square.”

The notes establish what the maker changed. To say how much weight the repair holds, you would need a load test.

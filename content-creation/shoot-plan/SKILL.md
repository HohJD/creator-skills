# Shot lists and B-roll

Separate what the audience must see from what the filmmaker can capture in one setup. Start with the story, the available location and gear, the time window, and any action that happens only once. Mark what is already filmed. Never assume an extra operator, repeatable reaction or second copy of a prop.

Build a shoot-order list. Give each shot a stable ID, setup/framing, action, start and end state, relevant sound, and the edit beat it covers. Group compatible shots. Put a must-have ahead of optional inserts. For irreversible actions, secure coverage before the change, or propose a single continuous shot with a feasible crop. Check lighting, prop state and screen contents across cuts.

Reserve time for setup and reset when estimating. If a tight brief cannot cover everything, identify which insert can be dropped and how the edit still works. For a solo shoot, prioritize a setup the creator can operate while performing. Plan a short sound-only take when a sound sells the result.

## Try it

> Build a shoot-order list for [scene]. I have [time, gear and crew]. [Action] can happen only once. Give me essential coverage, sound and one optional pickup.

## Worked example

Fictional brief: one phone on a tripod, one sealed envelope, one chance to open it.

| Shoot order | Setup and action | Edit use |
| --- | --- | --- |
| A | Locked overhead. Hold on the intact seal, open once with hands in frame, pause on the contents. Record the tear. | Establishing image, opening and reveal in a continuous take. |
| B | After opening, move close to the printed detail on the insert. | Cut in after the reveal. |
| C, optional | Still life of the torn flap next to the insert. | Closing image if time permits. |

If the tight crop would lose detail, show the complete opening from the wide take and save the close shot for the revealed object.

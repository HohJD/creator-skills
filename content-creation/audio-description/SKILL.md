# Audio-description writing

Identify what a listener cannot infer from the existing speech or meaningful sound. Inspect the video and audio where available; otherwise use the supplied visual and sound log and state its limits. Prioritise actions, layout changes and essential on-screen text that affect understanding. Use present-tense concrete language and consistent identifiers. Never infer an emotion, identity or cause that is not evident.

Place description where it can be heard. Keep dialogue, signature sounds and relevant silence intact. If the existing narration can naturally carry a needed visual fact, suggest an integrated rewrite. When no suitable gap exists, propose an extended pause, revised narration or a descriptive transcript as appropriate. Distinguish a timing plan from a checked performance; test the spoken line against the actual window before calling it synced.

Return a cue sheet with source locator, essential visual, proposed words and audio constraint. Exact times require evidence. For source audio in text, use subtitles; for a single photo, use image descriptions.

## Copyable brief

> From [final video or visual/sound log], describe only what a listener needs. Keep the dialogue and [sound] clear. Mark lines needing a timed read.

## Worked example

**Fictional input.** Verified log: during a silent gap from 00:07 to 00:10, the label changes from Draft to Sent. At 00:10 a confirmation chime plays.

**00:07–00:10, silent gap:** “The label changes from Draft to Sent.” Time the spoken read before recording. If the take runs long, try “Draft changes to Sent.” End before the chime. The chime is already audible; it can carry its own beat.
